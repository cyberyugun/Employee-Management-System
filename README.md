# Employee Management

## Requirements

- Node.js `22.22.3`, `24.15.0`, or `26.0.0` and compatible patch releases.
- npm `10.9` or newer.
- A modern browser (Chrome, Edge, Firefox, or Safari).

## Installation

```bash
npm install
```

## Run the application

```bash
npm start
```

Open `http://localhost:4200` in your browser.

## Production build

```bash
npm run build
```
